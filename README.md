# Smart System Automation & Monitoring Suite

A Linux and Python automation project built to make common system tasks easier, faster, and more organized. The project contains two applications: one focused on Linux system automation and another focused on menu-driven Python file automation.

## Overview

This repository contains a practical automation suite with two main applications:

- `linux_app/` - Linux automation with monitoring, backups, scheduling, maintenance, and report generation.
- `python_app/` - Menu-driven Python automation with file operations, logging, analytics, and error handling.

The goal of this project is to show how scripting can automate repeated tasks, reduce manual work, and create useful reports from system or file data.

## Features

### Linux Automation App

- System monitoring
- Backup automation
- Scheduled maintenance support
- Report generation
- Useful shell scripts for repeated Linux tasks

### Python Automation App

- Menu-driven interface
- File and folder operations
- Logging support
- Error handling
- Basic analytics and reporting

## Tech Stack

- Python
- Bash / Linux shell scripting
- Linux command-line tools
- File handling
- Logging
- Task scheduling concepts

## Project Structure

```text
smart-system-automation-suite/

```

## How to Run

### Linux App

```bash
cd linux_app
bash main.sh
```

### Python App

```bash
cd python_app
python main.py
```

Note: File names may differ depending on the final script names inside each folder. Check the folder contents before running.
