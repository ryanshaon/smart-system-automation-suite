Smart System Automation & Monitoring Suite
Problem Statement
A technology-driven organization manages multiple systems that require continuous monitoring, periodic main-
tenance, and efficient file management. Currently, many of these tasks are performed manually, leading to in-
efficiencies and missed schedules. To improve reliability, the organization plans to develop aSmart System
Automation & Monitoring Suiteconsisting of two applications:
1. Linux-Based Automation System (Ubuntu + Cron)
This system focuses on automating system-level tasks using Linux commands and cron scheduling. It must monitor
system resources, perform backups, execute scheduled scripts, and store logs for analysis.
2. Python-Based Automation System
This system focuses on building a menu-driven Python application to automate file operations, monitor system
performance, schedule tasks, maintain logs, and generate analytical reports.
Application 1: Linux-Based Automation System
Part A: System Monitoring Setup
Design a mechanism to periodically monitor system performance. The system should collect information related
to:
•Running processes
•Memory usage
•Disk utilization
•Network activity
The collected data must be stored in a file for further analysis.
Part B: Automated File Management
Extend the system to perform periodic file management tasks such as:
•Creating backups of important directories
•Compressing and storing backup data
•Synchronizing files between directories
Ensure that these operations are organized and stored systematically(Select the important directories from
your system and mention the description of the directories and perform above operations on it).
Part C: Scheduled Execution
Design the system such that all monitoring and file management tasks are executed automatically at regular
intervals without manual intervention.
Requirement:
•Configure a scheduling mechanism in Linux
•Ensure tasks run repeatedly based on defined intervals
•Maintain execution logs
The 3-day data of logs and scheduling operations should be stored in output files.

Part D: System Maintenance Automation
Incorporate periodic maintenance tasks into the system. These should include updating and cleaning the system
to ensure optimal performance.
Part E: Linux Report Generation
Generate a consolidated report summarizing:
•System resource usage
•Backup operations performed
•Frequency of scheduled executions
•Overall system status
Important Note- The above application should be designed with respect to your system directories and files.
Your username should be included in the output screenshot of each code, and the explanation and description of

Application 2: Python-Based Automation System
Part F: Directory Management Model
Design a structured representation to manage multiple directories. Each directory should store:
•Path information
•Number of files
•Last accessed or updated time
Part G: Interactive Menu System
Develop a menu-driven application that allows users to interact with the system. The menu should provide options
to:
•View directory status
•Perform file operations
•Execute automated tasks
•Generate reports
Part H: File Automation Engine
Implement a flexible system that allows users to perform file operations such as:
•Organizing files
•Renaming and removing files
•Copying and moving data
The system should handle different file types and directories dynamically.
Part I: Logging and Time Tracking
Integrate a logging mechanism to track:
•User actions
•System operations
•Errors and exceptions
Additionally, track timestamps for all major operations.

Develop an analytical module that processes collected data and generates insights such as:

Ensure the application is resilient by handling:
