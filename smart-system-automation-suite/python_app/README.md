# Python-Based Automation System

## Main File

- `automation_suite.py` - Menu-driven automation program implementing parts F-K.

## Stored Data

- `data/directories.json` - Tracked directory list.
- `data/operations_history.json` - Action history for analytics.
- `logs/automation.log` - Runtime logs.
- `reports/` - Analytics and task bundle reports.

## Run

```bash
cd /home/<username>/smart-system-automation-suite/python_app
python3 automation_suite.py
```
